# Telangana Welfare Navigator

## Problem Statement
Many citizens are unaware of the government welfare schemes they are eligible for due to scattered information and complex eligibility criteria.

## Solution
An AI-powered assistant that recommends government schemes based on a user's profile and provides eligibility details, required documents, and application guidance.

## Features
- Scheme Eligibility Checker
- Personalized Recommendations
- AI Chatbot Assistance
- Required Documents List
- Application Process Guidance

## Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: FastAPI, Python
- AI/RAG: LangChain, FAISS, Sentence Transformers
- Database: SQLite/PostgreSQL
- LLM: Hugging Face/Ollama

## Installation

### Clone Repository
```bash
git clone <repository-url>
cd telangana-welfare-navigator
```

### Backend Setup
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend Setup
```bash
npm install
npm run dev
```
