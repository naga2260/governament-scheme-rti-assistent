# Security Policy

## Supported Versions

The latest commit on the default active branch is supported for security fixes.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to the project maintainers. Do not publish exploit details or sensitive information in public issues.

When reporting, include:

- Affected file, feature, or deployment URL
- Steps to reproduce
- Expected and actual impact
- Any logs or screenshots that do not expose secrets

The maintainers will review the report, assess severity, and prepare a fix where appropriate.

## Secrets

Do not commit API keys, Streamlit secrets, `.env` files, tokens, or credentials. Use Streamlit secrets or deployment environment variables.
